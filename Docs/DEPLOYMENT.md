# Большая деревня и ручная высадка

- Деревня: 9×7, 63 уникальных участка; дом в центре, заселение по спирали.
- Сохранения версии 1 при загрузке GameStore мигрируют в версию 2: старые координаты 5×4 переносятся к новому центру, без изменения ID и уровней. Ключ UserDefaults прежний.
- Атака в приложении: первый тап в нижней половине арены начинает бой и выпускает следующего кота из детерминированной очереди `armyStats`. Перетаскивание показывает призрак; отпускание вне разрешённой половины отменяет высадку.
- Авто-высадка выпускает оставшихся котов снизу. Резерв предотвращает преждевременное поражение, но не отменяет лимит 180 секунд после первого кота. Пауза блокирует ручную высадку; авто-высадка возобновляет бой.
- Старый `BattleSim(state:enemy:mode:seed:)` остаётся автоматическим. Новый overload с `manualDeployment` предназначен для атаки. Оборона не меняется. `runToEnd()` высаживает резерв, чтобы headless-бой всегда завершался.
- RNG, таблицы баланса и EnemyGenerator не изменены.

## Арты

23 оригинальных AI-generated ассета: шесть врагов, две постройки, четыре ресурса, четыре кнопки, фон, четыре декора, два эффекта. Ассеты Supercell не использовались.

Сырые листы в игнорируемом `raw/`. Для повторной обработки при наличии оригиналов:

```sh
python3 -m venv /tmp/catclans-art
/tmp/catclans-art/bin/pip install Pillow
/tmp/catclans-art/bin/python Scripts/split_asset_sheets.py
/tmp/catclans-art/bin/python Scripts/process_assets.py
```

Фон карты сохраняется непрозрачным; у спрайтов удаляется серый фон. Разрезы листов учитывают реальные размеры генераций.
