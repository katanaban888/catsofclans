# 🐱 КотоКланы (Cat Clans)

Клон Clash of Clans про котов: деревня, постройки, производство ресурсов,
обучение армии, осады вражеских баз и оборона от налётчиков.
Всё написано на **Swift**: чистое ядро без зависимостей + SwiftUI-приложение для iOS.

> Реализация проверяется синтаксическим анализом и детерминированным Python-портом
> движка (баланс подогнан на нём); для запуска нужен Xcode 15+ / Swift 5.9+.

## Как запустить

### iOS-приложение (основной путь)
1. Откройте `CatClans.xcodeproj` в Xcode.
2. Выберите target **CatClans**, устройство (симулятор iPhone или ваш iPhone).
3. **Run** (⌘R).

Если проект не открывается — пересоберите:
```bash
python3 Scripts/generate_xcode_project.py
```

### Консольное демо (Linux/macOS, без Xcode)
```bash
swift run CatClansDemo
```
Покажет «полный игровой день»: производство, постройку, обучение,
атаку базы с логом боя, оборону от рейда, оффлайн-доход.

### Тесты
```bash
swift test
```

## Как играть

**Ресурсы:** 🐟 рыба (фермы-ловушки), 🥛 сливки (бочки), 🧶 пряжа (клубки),
🐭 мыши (Мастерская усов, только в бою).

**Цикл игры:**
1. Стройте и улучшайте: Фермы, Академия, Мастерская усов (ускоряет и усиливает
   армию), Стрелковая вышка и Пушка (оборона), Котоловушка (оглушает), Забор.
2. В Академии обучайте котов:
   - 🐱 Котёнок — дешёвая пехота
   - 🐯 Кот-воин — тяжёлая пехота
   - 🐭 Кот-мышелов — дальнобой
   - 🪄 Кот-волшебник — AoE-урон по площади
   - 🐅 Тигр — тяжёлый боец (Дом котов 4+)
3. Атакуйте базы противника (⏱ кулдаун 2 минуты). Уровень базы растёт
   вместе с уровнем игрока: сурки → еноты → грабители → бродячие собаки →
   волчья стая с Альфой.
4. Защищайтесь: каждые ~10 игровых минут по вам идёт рейд. Башни и
   котоловушки срабатывают автоматически; HP Дома котов восстанавливается
   2%/сек (полный ремонт ~8 минут).

**Правила боя:**
- Атака: 3 минуты. Победил — весь лут. Провалил — уносят 40% от уничтоженной
  доли базы. «Отступить» можно в любой момент.
- Оборона: 30 секунд штурма, потом налётчики уходят. Дом разрушен —
    противник забирает 20% запасов, но дом восстанавливается до 35% HP.
- Котоловушка оглушает врага на 2.5 секунды (на каждого — один раз).

**Прочее:**
- Оффлайн-доход: пока игра закрыта, ресурсы копятся (кап 12 часов), обучение
  продолжается, рейдов нет.
- Прогресс сохраняется автоматически (UserDefaults, ключ `catclans.save.v1`).
- Все бои детерминированы по seed — тот же состав армии + тот же seed = тот же бой.

## Архитектура

- **CatClansKit** — чистый Swift, без Foundation-зависимостей от платформ
  (только `Foundation` для Codable/Date). Легко тестировать и, при желании,
  собрать под любой таргет: iOS-приложение, watchOS, server.
- **BattleSim** — пошаговый симулятор (такт 0.1 с, карта 40×40): башни стреляют,
  юниты ходят по ближайшей цели (стены танкуют, ловушки стазнят), AoE, лимит
  времени. Симуляция отделена от рендера: приложение просто вызывает `step()`
  по таймеру и рисует снапшоты.
- **GameStore** (приложение) — единственный `ObservableObject`: один таймер
  деревни (1 с) + таймер боя (0.1 с × скорость 1/2/4), автосохранение.
- **Xcode-проект** генерируется скриптом, чтобы в репозитории не тасовался
  бинарный мусор и не было дрейфа между манифестами.

## Замечание о проверке кода

В этой среде нет Swift-компилятора, поэтому кодо-баз проверена:
1. парсером tree-sitter (синтаксис всех 25 Swift-файлов — без ошибок);
2. Python-портом движка боя 1:1 — баланс подогнан на нём
   (прогрессия 5 уровней баз, рейды, лимит времени атаки);
3. ручным ревью каждого файла (типы, инициализация, Swift-семантика).

Если `swift build`/`swift test` покажут ошибку — напишите сюда, поправлю за минуту.
